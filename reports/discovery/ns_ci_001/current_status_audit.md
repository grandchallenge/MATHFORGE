# NS-CI-001 current-status and source audit

**Audit date:** 2026-07-23  
**Parent:** `grandchallenge/MATH-PROGRAMME#55`

## Determination

The universal estimate

```math
u\in L^4(0,T;L^6(\mathbb R^3))
```

for every three-dimensional Leray–Hopf solution generated by all admissible smooth rapidly decreasing divergence-free data is not known. The official Clay page continues to list the underlying existence-and-smoothness problem as unresolved.

This is a status determination, not a proof that no unpublished argument can exist. A claimed resolution changes programme status only after acceptance through an appropriate mathematical review and the MATH-PROGRAMME claim-promotion process.

## Material correction to the initialized challenge

The draft campaign used

```math
u_0\in C_c^\infty(\mathbb R^3)
```

as its canonical initial-data class. Fefferman's official whole-space positive branch is broader: it quantifies over every smooth divergence-free field whose derivatives decay faster than every power, as specified by condition (4).

Therefore:

1. a universal theorem for compactly supported data would be a major restricted result;
2. it would not, by itself, settle the entire official whole-space positive branch;
3. the canonical NS-CI challenge should use the Fefferman rapidly decreasing class;
4. compact support should remain a named restricted lane.

No density argument may silently replace this missing data-class extension. The target estimate is nonlinear and critical; a valid extension would require a stability theorem preserving the required solution and norm controls.

## Operational Ladyzhenskaya–Prodi–Serrin interface

The audited modern operational statement is:

> Let `u` and `u_tilde` be Leray–Hopf weak solutions on `R3` with the same initial datum. If
>
> ```math
> u\in L^r(0,T;L^q(\mathbb R^3)),\qquad \frac2r+\frac3q=1,\qquad q>3,
> ```
>
> then the solutions agree. With `H1` initial data, the controlled solution is strong through the initial time.

The pair `(r,q)=(4,6)` is included.

Historical attribution is more delicate:

- Prodi's original theorem has been extracted. It proves uniqueness under
  `L^(2p/(p-3))_t L^p_x`, including `L4_tL6_x`, but in his own generalized mixed-problem framework.
- Serrin's bibliographic record is verified, but the exact original theorem text was not available through the audited public endpoint.
- Ladyzhenskaya's original Russian full text is located, but exact theorem translation remains pending.

The programme may use the modern operational statement while keeping the historical theorem-text obligations visible.

## One-way correspondence with the Clay positive branch

Let the canonical universal challenge quantify over Fefferman's rapidly decreasing smooth divergence-free data. Then the following implication is supported:

```text
universal L4_tL6_x integrability for every Leray-Hopf solution
    + global Leray weak existence
    + the operational LPS theorem
    + weak-strong uniqueness
    + local strong existence
    -> a global smooth solution with the official whole-space data class.
```

The energy inequality supplies the bounded-energy requirement.

This establishes that the full-data NS-CI target is **sufficient** for Clay statement (A), subject to the exact standard solution-interface conventions recorded in the source ledger.

## Why bidirectional equivalence is not yet promoted

The reverse implication is plausible in the standard PDE framework but is not being promoted solely from Fefferman's wording. The official statement requests a globally smooth solution with bounded kinetic energy; the reverse route must still record why that solution belongs to the local strong class needed for

```math
\int_0^T\|u(t)\|_6^4\,dt<\infty
```

on each finite interval, and why every Leray–Hopf solution with the same datum agrees with it.

Accordingly, the campaign wording is:

> Universal critical integrability for the Fefferman data class is sufficient for the whole-space positive Clay branch. Full bidirectional equivalence remains conditional on the reverse strong-class and weak–strong correspondence audit.
