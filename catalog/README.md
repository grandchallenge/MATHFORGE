# GCL external mathematical intake and semantic catalog

This directory is MATHFORGE's provider-neutral, content-addressed intake catalog. It separates immutable source accounting from semantic review and from every downstream form of mathematical authority.

## Assurance ladder

1. `SOURCE_LOCKED` preserves an exact source object.
2. `NORMALIZED_REPLAYED` adds deterministic extraction and normalization.
3. `SEMANTICALLY_REVIEWED` records a qualified comparison with the source.
4. `CAMPAIGN_CONCORDANT` records an exact reviewed relation to a Programme target.

The ladder does not include certification. A MATHCERT certificate may be linked by a separately governed handoff, but no tier implies one.

## Provider posture

`governance/external_sources.json` is the current v2 provider registry. ResearchMath is one corpus provider. `FC-GDM-001` and `FC-GDM-002` are historical scope aliases under the single `FC-GDM` provider lineage. Their original records remain immutable evidence in the migration ledger.

The weekly observer records upstream movement without changing admitted identity. The monthly replay produces an admission candidate and compares its generated bytes with the protected catalog. A changed or disappeared statement invalidates affected relations until replay and review are renewed.

## Boundaries

- MATHFORGE owns source locking, extraction, normalization, catalog construction, and review evidence.
- MATHSOLVE may receive proposals from `SEMANTICALLY_REVIEWED` entries; exact imported campaign targets require `CAMPAIGN_CONCORDANT`.
- MATH-CORE may receive read-only provenance-bound nodes and typed edges. Catalog events cannot mutate its canonical Claim Ledger.
- MATHCERT receives only separately scoped local claims and evidence. Catalog status, upstream proof annotations, and campaign relations are not certificates.

## Replay

ResearchMath:

```text
python catalog/build_semantic_catalog.py build-researchmath --input <pinned-train.jsonl>
```

DeepMind Formal Conjectures:

```text
lake exe extract_names FormalConjectures --exclude=docstring,moduleDocstrings > <inventory.json>
python catalog/build_semantic_catalog.py build-formal-conjectures --checkout <pinned-checkout> --inventory <inventory.json>
```

Finalize and verify:

```text
python catalog/build_semantic_catalog.py finalize
python catalog/build_semantic_catalog.py verify
```

Every catalog shard is deterministic JSON Lines. Provider manifests bind its byte length, SHA-256 digest, count, and first and last stable catalog identifiers.
