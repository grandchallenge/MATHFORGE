# ResearchMath-14k corpus intake

This directory is the canonical MATHFORGE intake lane for pinned rows from
`amphora/ResearchMath-14k`. It is a corpus-row lane, distinct from the formal
statement repository lane under `formal_sources/`.

`RM-DIO-004` pins dataset commit, LFS object, Viewer coordinates, source row,
reliability assessment, problem card, and provisional handoff. Corpus metadata
is discovery evidence only. It cannot establish Programme status, semantic
equivalence, proof, novelty, campaign authority, or MATHCERT certification.
